# LOGO 墙图片目录 / Logo wall

登录页、注册页登录卡片上方的 LOGO 墙会**自动收录本目录中的图片**，无需后台操作：

- 支持格式：`png` / `jpg` / `jpeg` / `gif` / `webp` / `svg`
- 建议尺寸：高 40~80px 的横版 LOGO，透明背景 PNG 最佳
- 文件名的 `-`、`_` 会显示为空格，作为鼠标悬停提示文字
  例：`aliyun-cloud.png` → 提示「aliyun cloud」
- 删除文件即从 LOGO 墙移除；按文件名字母顺序展示
- 后台「系统设置 → LOGO 墙」中上传的图片会排在目录文件之前

站点主 LOGO（登录页左侧品牌区）请在后台「系统设置 → 站点 LOGO」上传，
或直接替换 `assets/logo/logo-mark.png`。
