# 优享财务系统 · 业务与财务一体化管理平台

一套面向 IDC / 云服务商的**原创**业务与财务一体化管理系统，包含业务系统、财务系统、三版本（普惠版 / 专业版 / 企业版）授权体系、域名授权校验、应用商店与 Logo 生成工具。

> **说明**：本项目为原创实现，仅在业务领域上参考了 IDC 计费类产品的通用功能（产品/订单/客户/账单/工单/续费/经营分析等），**未复制任何第三方产品的代码、文案或品牌资源**。系统名称、模块划分、数据结构、界面与文案均为独立设计。

## 一、功能总览

### 1. 财务系统
| 模块 | 说明 |
|---|---|
| 收支流水 | 全量资金变动流水，记录方向、分类、操作人、变动后余额，可追溯 |
| 余额与钱包 | 客户余额、授信额度、钱包总额统计 |
| 订单管理 | 新购 / 续费 / 充值 / 应用订单，支持余额支付、线下收款、取消、退款 |
| 账单中心 | 自动生成账单（开通、续费），支持手工账单、结清、作废、逾期标记 |
| 支付对接 | 易支付 / 聚合码通用协议（下单签名、回调验签、金额校验、幂等处理） |
| 支出登记 | 机房、带宽、授权费、人员成本、渠道佣金等站方支出 |
| 经营分析 | 收支汇总、净利率、客单价、收入构成、产品销量 Top、客户消费 Top（企业版） |

**财务一致性保障**：余额变更全部在数据库事务内完成，扣款使用 `UPDATE ... WHERE balance >= ?` 带条件更新，从根上避免并发超扣与负余额。

### 2. 业务系统
| 模块 | 说明 |
|---|---|
| 产品与套餐 | 产品分组、多计费周期（月/季/半年/年，年付 9 折、半年付 95 折）、库存、自动开通标记 |
| 业务实例 | 开通 / 暂停 / 恢复 / 终止 / 续费的状态机，含 IP、主机名、登录信息（AES 加密存储） |
| 资源节点 | 节点容量与已用统计，接口密钥加密存储（企业版） |
| 工单协同 | 部门分派、优先级、客户与客服双向对话、关闭归档（专业版） |
| 自动续费 | 到期后（或提前 N 天）自动扣费顺延，含金额安全防护（专业版 + 定时任务） |
| 到期提醒 | 展示 N 天内到期业务清单 |
| 渠道 / 代理 | 佣金比例、自动结算、提现登记、名下客户（专业版） |
| 优惠券 | 固定金额 / 百分比、门槛、发行量、有效期（专业版） |

**自动续费的金额安全（会真实扣费，勿轻视）**

后台「系统设置 → 开启到期自动续费」控制总开关，`renew_ahead_days` 控制提前天数（0 = 到期当天才扣）。执行时序为：

```
查询到期候选 → claimRenew() 原子抢占期限 → 扣费 → 成功则生成已结清账单
                                              └ 失败则 rollbackRenew() 归还期限
```

- **防重复扣费**：抢占采用「调用方快照比对 + CAS 更新」——只有观测到的到期日与库中一致时才允许顺延。
  因此多个 cron 进程、或 cron 与手动/URL 触发叠加时，**同一笔业务只会被扣一次**；
  第二次会拿到「到期日已变化」并跳过。
- **失败不留痕迹**：余额不足时立即归还期限，保持原到期日、不生成账单，下次定时任务继续尝试。
- **可审计**：每笔续费在 `runtime/cron.log` 有明细行，并可在「账单中心」「收支流水」核对。
- 价格为 0 的免费业务不会被处理；已终止的业务不会被处理。

### 3. 三版本授权体系
在后台 **「版本与模块」** 一键切换，菜单与接口自动收敛：

| 版本 | 能力范围 |
|---|---|
| 普惠版 | 客户、产品、订单、账单、收支记账、商店浏览 |
| 专业版 | + 工单、自动续费、优惠券、渠道代理、商店购买与安装 |
| 企业版 | + 多节点、分站、开放 API、经营分析、授权中心对外签发、批量导出 |

功能 → 最低版本映射集中定义在 `includes/edition.php` 的 `FEATURES` 常量，新增功能只需加一行。

### 4. 域名授权校验
- **查询优先顺序**：本地缓存 → 官方授权接口（按域名）→ 本地授权表回退
- **结论展示**：命中授权 → `域名已正版授权`；未登记 → `域名未在官方授权`；另区分 `授权已过期` / `已被封禁`
- **授权码按域名签发**：同一「域名 + 版本 + 到期日」生成结果稳定可复核（HMAC-SHA256），无需保存明文
- **对外查询接口**：`GET api/license.php?domain=xxx`，返回 JSON，可选 HMAC 签名校验
- **强制收敛开关**：未授权时默认只提示不限制版本；开启 `license_enforce` 后自动收敛为普惠版
- **离线可用**：`offline_ok` 为真时，官方接口不可用会回退本地授权表，不阻断业务

### 5. 应用商店
分类覆盖：支付通道、实名认证、云服务对接、系统增强、通知消息、前台主题、运维工具。
每个应用含版本、作者、价格、所需版本、兼容性、更新日志、下载量、销量；支持：

- 免费应用一键安装 / 付费应用下单购买
- **授权与域名绑定**：安装时按绑定域名签发授权码，更换域名自动重新签发，旧码失效
- 上架 / 下架 / 编辑 / 删除、推荐位、分类管理、安装记录管理
- 远端源同步（配置 `store.remote_api` 后可从官方商店拉取应用列表）

### 6. 上游对接与自动开通
对接资源供应商，实现"客户付款 → 自动开通"。

- **驱动式架构**：内置「本地模拟」与「通用 HTTP/JSON」两种驱动；新增厂商只需实现 `YxUpstreamDriver` 接口（开通/续费/开关机/重装/销毁/状态查询）并登记，业务层零改动
- **产品映射**：本地产品 ↔ 上游产品编码 + 规格 JSON + 成本价；支持「拉取上游产品」辅助填写
- **全异步执行**：开通/续费/开关机/重装/销毁统一进任务队列，失败按 1/5/15/60/120 分钟退避重试，绝不阻塞客户下单
- **结果回写**：上游返回的实例编号、IP、登录账号密码自动回写到业务实例（密码 AES 加密存储）
- **可观测**：「任务队列」页面可查看每个任务的状态、尝试次数、下次重试时间与失败原因，支持立即执行/重试/取消
- 未绑定上游的产品不受影响，仍走人工开通

### 7. 下游开放接口（OpenAPI）
把能力开放给你的代理商 / 分销系统。

- **鉴权**：AppID + AppSecret，HMAC-SHA256 签名
- **六重防护**：验签 → ±300 秒时效 → nonce 一次性防重放 → IP 白名单（支持 `1.2.3.*` 与 `10.0.0.0/8`）→ 动作最小授权 → 每分钟限流
- **动作集**：`ping`、`product.list/detail`、`order.create/pay/query/list`、`service.list/detail/renew/operate/sync`、`balance.query`、`license.query`
- **终端用户映射**：按 `appid + external_user_id` 自动为下游终端用户建档，互不干扰
- **幂等下单**：下游传入 `external_sn`，重复请求返回同一订单，避免重复开通
- **数据隔离**：不同应用之间无法互查订单与业务（返回 404 而非 403，不泄露存在性）
- **事件回调**：`order.paid` 等事件推送到下游 `notify_url`，同样经队列重试
- **全量留痕**：每次调用记录 appid、动作、结果、耗时、IP 与脱敏参数，保留 30 天

完整协议、签名示例（PHP / Python）与排查手册见 **`docs/接口对接说明.md`**。

### 8. 结构与数据升级
- `YxSchema::sync()`：对比 `includes/schema.php` 定义与实际库结构，**只做加法**（建缺失表、补缺失列、补缺失索引），不删列不删表
- 安装向导已改为增量模式，重复安装只补齐结构并保留数据
- 独立升级工具：
  ```bash
  php tools/upgrade.php --dry-run   # 只列出将要执行的变更
  php tools/upgrade.php             # 正式执行
  ```
- 同一套 SQL 生成逻辑同时适配 MySQL 与 SQLite（含 `ADD COLUMN` 的方言差异与安全降级）

### 9. 授权模式（正式版 / 开源版）
后台「系统设置 → 授权模式」一键切换：

| 模式 | 行为 |
|---|---|
| `official` 正式版 | 按域名向官方接口 / 本地授权表校验，展示「域名已正版授权」或「域名未在官方授权」，可按授权版本收敛功能 |
| `community` 开源版 | **授权模块整体不启用**：不联网校验、不写校验日志、不做版本收敛，界面统一显示「开源版 · 未启用授权模块」 |

> 开源版是**正式的发行模式**（用于分发免费/开源版本），不是代码级绕过：
> 它不会把未授权站点显示成「已正版授权」，也不会伪造任何授权结论。

### 10. 关于我们（公司信息）
前台 `about.php` 是一个**内容全部可后台编辑**的公司介绍页，后台入口「系统 → 关于我们」。

| 板块 | 数据形式 | 说明 |
|---|---|---|
| 页面标题 / 一句话定位 / 公司简介 | 标量 | 简介支持多段（空行分段） |
| 我们的能力 | 列表（可选图标） | 卡片宫格 |
| 实力数据 | 列表 | 数值 + 说明，如「10 年+ / 5000+」 |
| 我们是谁 / 品牌释义 | 标量 | 两栏展示 |
| 我们的理念 | 列表 | 自动编号 |
| 发展历程 | 列表 | 年份 + 节点 + 说明，时间线样式 |
| 合作伙伴 | 列表（可带链接） | 卡片列表 |
| 加入我们 / 团队福利 | 标量 + 列表 | 可整体留空隐藏 |
| 联系我们 | 标量 | 邮箱/QQ 未单独填写时回退到「系统设置」里的全局联系方式，避免两处重复填写 |

设计约定：

- **留空的字段与空板块自动跳过**，不会出现半成品页面
- 导航中的「关于我们」入口只在**有内容时**才显示
- 可在后台一键关闭该页面（关闭后返回 404）
- **默认不预置任何公司事实**（成立时间、客户数量、合作伙伴名单、联系方式、招聘信息一律留空并给出填写提示），
  只预置能确定的产品能力描述。默认内容由 `YxAbout::seedDefaults()` 写入，**安装与升级共用同一份实现**，
  且只补缺失项、不覆盖已有人工修改
- 文本内容存 `yx_setting`（`about_*`）与 `yx_about_item`，无需改代码

### 11. Logo 生成
```bash
# 默认（蓝色图标 + 深色文字）
php tools/gen_logo.php

# 自定义颜色与名称
php tools/gen_logo.php --mark=#ef4444 --mark2=#b91c1c --glyph=#ffffff --text=#000000

# 指定字体
php tools/gen_logo.php --font=/usr/share/fonts/xxx.ttf --name="优享财务系统"
```

可用的颜色参数：

| 参数 | 作用 | 默认 |
|---|---|---|
| `--mark` / `--mark2` | 图标渐变起止色 | `#4dabf7` / `#3b5bdb` |
| `--glyph` | 图标内图形（上升柱状）颜色 | `#ffffff` |
| `--text` | 中文名称颜色 | `#1f2733` |
| `--subcolor` | 英文副标题颜色 | `#7d8799` |
| `--name` / `--sub` | 中文名称 / 英文副标题文案 | 优享财务系统 / YOUXIANG FINANCE |

产出 `assets/logo/`：`logo-mark.png`(64)、`logo-mark@2x.png`(128)、`favicon.png`(32)、`favicon.ico`、`logo.svg`(矢量)、`logo-main.png`(横版 360×96)，并在**站点根目录**写入 `favicon.ico`（避免浏览器自动请求 `/favicon.ico` 时产生 404 日志）。

- 图标为纯几何图形（渐变圆角底 + 上升柱状图符），**不依赖字体**，任何环境都能生成
- **`logo-main.png`（含中文的横版）需要系统中文字体**，未找到时自动跳过并提示，避免生成一排空框的假 Logo
- 服务器无中文字体时安装（CentOS 7）：
  ```bash
  yum install -y adobe-source-han-sans-cn-fonts   # 思源黑体简中，EPEL 源
  # 或 yum install -y wqy-microhei-fonts          # 文泉驿微米黑，base 源
  ```
- 字体发现逻辑会**优先选择 Regular 字重**（避免拿到 Bold 导致副标题过重）
- UI 中引用的是 `logo-mark.png`（图标）＋ HTML 文本（站名，由「系统设置 → 系统名称」控制）；
  `logo.svg` 与 `logo-main.png` 是提供给邮件签名、宣传物料、应用商店等场景使用的完整 logo

## 四、安装

1. 把本项目放到站点根目录（例如 `/www/wwwroot/your-domain/`）。
2. 浏览器访问 `https://你的域名/install/install.php`。
3. 填写：
   - 系统名称、**初始版本**（普惠版 / 专业版 / 企业版）
   - 管理员账号与密码（≥8 位）
   - 数据库：推荐 MySQL（宝塔「数据库」中先建库与账号）；单机自用可选 SQLite
4. 提交后自动完成建表（21 张表）与默认数据写入。
5. **安装完成后请限制 `install/` 目录访问**（见 `docs/部署说明.md`）。
6. 入口：
   - 门户 `https://你的域名/`
   - 后台 `https://你的域名/admin/`
   - 用户中心 `https://你的域名/user/`
   - 应用商店 `https://你的域名/store/`

> 重复执行安装向导只会补齐缺失表与默认数据，**不会清空既有数据**。

## 五、验证

### 端到端自检（推荐）
```bash
cd /www/wwwroot/你的站点目录
php tools/selftest.php
```

## 六、授权对接协议

其它站点把 `includes/config.php` 的 `license.official_api` 指向你的授权中心（或直接在后台「系统设置 → 官方授权服务器地址」填写），即会按域名自动校验。

**请求**
```
GET {official_api}/api/license.php?domain=www.example.com&ts=1699999999&version=1.0.0&sign=xxxx
```
签名（可选，配置 `license.channel_secret` 后强制）：
`sign = HMAC-SHA256("domain=..&ts=..&version=..", channel_secret)`

**响应**
```json
// 已授权
{"code":0,"msg":"域名已正版授权","data":{"domain":"www.example.com","authorized":true,
  "status":"authorized","edition":"pro","expire_at":"2027-12-31","license_key":"66BE-9179-121E-75E1"}}

// 未授权
{"code":0,"msg":"域名未在官方授权","data":{"domain":"pirate.com","authorized":false,
  "status":"unauthorized","message":"域名未在官方授权"}}
```
`status` 取值：`authorized` / `unauthorized` / `expired` / `banned`，与本地判定语义完全一致。

## 七、定时任务

在宝塔面板「计划任务」新增 Shell 脚本，每 10 分钟执行：
```bash
php /www/wwwroot/你的站点目录/tools/cron.php --token=后台生成的任务令牌
```
执行内容：到期业务标记 → 自动续费（需开启 `auto_renew`）→ 授权巡检。日志追加写入 `runtime/cron.log`。

## 八、安全设计

- 所有 SQL 使用 **PDO 预处理语句**，杜绝拼接注入
- 所有写操作校验 **CSRF 令牌**（校验失败返回 419 并终止）
- 密码使用 `password_hash`（bcrypt），登录失败达阈值触发**临时锁定**
- 业务登录密码、节点接口密钥使用 **AES-256-CBC 加密存储**
- 支付回调**验签 + 商户号校验 + 金额校验**，金额不符记录异常并拒绝
- 订单支付**幂等**：重复回调不会重复扣款或重复交付
- 管理端**操作审计**（操作人、动作、对象、IP、明细）
- 未授权/异常提示不暴露内部路径与堆栈
- 建议生产环境关闭 `app.debug`

1. **支付网关**：内置易支付 / 聚合码通用协议实现（下单、签名、回调、验签）。若你的通道字段或签名规则不同，请只改 `includes/payment.php` 一处。
2. **上游对接**：驱动框架与任务队列已完整实现（含自动开通、续费、开关机、重装、销毁、状态回写与失败重试）。内置「本地模拟」驱动可直接跑通全链路；对接**真实**厂商时，需按对方接口文档新增一个驱动类（实现 `YxUpstreamDriver` 的 8 个方法），HTTP 驱动可直接用于符合本文档协议的上游。
3. **分站 / 多站点**：企业版能力位已预留（`subsite`），当前以渠道（`agent`）模块承载分销场景。
4. **发票开具**：账单中心已具备发票单据流，实际开票（对接税控）未实现，可在工单流程中人工处理。

7. **数据库升级**：新增功能需要的表与字段通过 `tools/upgrade.php` 增量补齐（只做加法）。升级前建议先备份数据库。
